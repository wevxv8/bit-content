## 先给结论：腾讯云备案需要服务器，具体是需要“腾讯云境内的接入资源”

腾讯云备案文档写得很明确：备案遵循“接入商备案”原则，只有网站部署在腾讯云服务器上时，才需要通过腾讯云提交 ICP 备案；服务器在本地机房或其他云厂商的，要找对应的接入服务商办理，腾讯云无法代为受理。

## 为什么备案要跟服务器绑定：接入商原则的几个推论

备案的本质是“谁接入、谁核验、谁负责”。备案制度要求网站通过接入服务商提交备案，腾讯云只能核验接入在自家平台上的网站，所以服务器在哪，备案就去哪办。

这条原则能解释不少看起来奇怪的情况：

- 域名在腾讯云注册，服务器在别家：去服务器那家备案，腾讯云受理不了。域名在哪注册不影响备案归属。
- 服务器从别家换到腾讯云：办接入备案，不用把原备案作废重来。
- 网站放在公司本地机房：找机房对应的接入服务商，不是随便挑一家云厂商。
- 腾讯云内部换 IP：非经营性备案通常不用重新备案；涉及经营性备案的，必须做变更备案，把登记的 IP 改过来。

## 没有自己的服务器，备案授权码能顶用吗

能顶一部分，但它背后仍然是一台腾讯云服务器。备案授权码由腾讯云服务器生成，实际指向这台服务器的 IP；提交备案时，它相当于你的接入凭证。

官方对“账号下没有可备案资源”的建议是：购买可备案资源，或者使用备案授权码。适合用授权码的情况大概是这样：团队或项目里已经有腾讯云服务器在用，只是备案账号下没有可备案资源；或者你不想为备案单独再买一台机器。

如果手上一台腾讯云服务器都没有，先确认能不能拿到可用的备案授权码；拿不到，就得买一台，或者干脆选择免备案的境外方案。

还有一点：授权码指向的是具体 IP，之后换服务器、换 IP，备案信息可能要跟着做接入或变更，别把它当成一劳永逸的通行证。

## 哪些情况不用服务器、也不用备案

域名注册后不建站、只用 IP 测试、服务器在境外，这几种情况都不需要备案。腾讯云文档的说法是：域名本身无需备案，但要实名认证；是否需要备案，取决于域名是否解析到中国境内服务器。

- 只注册了域名，暂时不用：不用备案，完成实名认证即可。
- 网站没做好，只用服务器公网 IP 访问测试：可以暂不备案。
- 服务器在中国香港、新加坡、美国等境外地域：不需要备案。
- 只买了服务器，不用域名：不需要备案。

有两个反例值得记住：用腾讯云 CDN 的域名要备案，未备案不能接入；用自己域名通过 mail.域名 访问企业邮箱，也要先给主域名做网站备案。

## 几个高频误区，踩了要返工

下面这些说法很常见，但基本都站不住脚，尤其是“换端口免备案”。

- **换非 80 端口就不用备案**：腾讯云文档明确，托管于中国境内服务器的网站，不论设置哪个端口都能被监测到。
- **三级域名都要单独备案**：二级域名在腾讯云已有备案的，三级、四级域名无需再备案；二级域名备案的接入商不是腾讯云，要做接入备案；二级域名本身没备案，才需要提交新备案。
- **两个新域名指向同一个已备案网站不用再备案**：目前一个网站只能提交一个域名，新域名要重新备案。
- **服务器到期不续费，备案放着不管也没事**：备案和接入资源绑定。腾讯云开发者社区有用户反映，服务器过期未续费、域名又解析到别家服务器后，备案被注销。这类处理以管局和接入商为准，但服务器不用了，备案该变更就变更、该注销就注销，别拖。

## 常见问题

**腾讯云域名备案必须买腾讯云服务器吗？** 想在腾讯云办，就需要腾讯云的接入资源：中国大陆地域的服务器，或这台服务器生成的备案授权码。

**用阿里云的服务器能在腾讯云备案吗？** 不能。服务器在阿里云就去阿里云办；反过来，腾讯云的服务器也不能拿到阿里云备案。

**香港服务器需要备案吗？** 不需要。使用中国香港服务器开办网站不需要备案，只有中国境内服务器才需要。

**域名在腾讯云注册、服务器在境外，要备案吗？** 不需要。判断依据是服务器托管位置，跟域名在哪注册无关。但如果用腾讯云 CDN 等境内服务，另有备案要求。

**只买服务器、不用域名，要备案吗？** 不需要。不用域名解析指向服务器时，不需要备案。

**备案授权码是什么？** 腾讯云服务器生成的授权凭证，实际指向该服务器的 IP，用于备案。
